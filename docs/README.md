# Project documentation

This directory contains maintenance and verification records:

- `PROVENANCE.md` documents upstream lineage, retained attribution, local
  modifications, and the repository reorganization.
- `VALIDATION.md` records the tested build environment, commands, output
  properties, and supported conclusions.
- `code-overview.md` explains the two scripts, their data flow, failure model,
  and maintenance boundaries.
- `mini-tutorial.md` provides a guided manuscript build without duplicating the
  command reference in the root README.
- `keywords.md` records five descriptive project keywords.

User-facing setup and compilation instructions remain in the repository-root
`README.md` so a new author sees them immediately.
